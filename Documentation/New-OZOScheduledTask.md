# New-OZOScheduledTask
This function is part of the [OZOTaskScheduler PowerShell Module](https://github.com/onezeroone-dev/OZOTaskScheduler-PowerShell-Repository/blob/main/README.md).

## Description
Creates scheduled tasks for running scripts. Uses PowerShell to run .ps1 scripts and CMD to run everything else. _New-OZOScheduledTask_ is an alias for [_Set-OZOScheduledTask_](Set-OZOScheduledTask.md).
